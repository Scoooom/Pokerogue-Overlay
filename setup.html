PokéRogue Overlay

📖 Docs

A local Node.js server that reads your live game state and serves dedicated browser sources for OBS. Add each route as a Browser Source and position it anywhere on your scene.

Quick Start
Getting set up in 3 steps
1
Start the server — open a terminal in this folder and run node server.js
2
Install the Tampermonkey script in your browser, then open pokerogue.net — data will start flowing automatically
3
In OBS, add a Browser Source for each route you want below. Set background to transparent (check Custom CSS → body { background: transparent; })
Browser Source Routes
GET /full
Main Overlay
Full-featured overlay panel showing your entire party with HP bars, moves, abilities, natures, and boss wave tracker. Includes an inline editor for manual data entry.
OBS Source Full Page
Preview
OBS tip: Use 1920×1080 browser source. Place your game capture behind this layer. The left panel is intentionally blank — that's where your game capture goes.
GET /wave
Wave Display
Compact widget showing the current biome, wave number, game mode badge, and a live next-encounter chip. Knows all Classic fixed battles — rival, evil team, Elite Four, Eternatus — and gym leader waves based on your cycle.
OBS Source Widget
Preview
ParameterTypeDescription
cycle 20 | 30 Gym leader cycle for this run. Omit if unknown — all possible gym waves will show as (?).
buttons flag Show the C-20 / C-30 / ? cycle selector buttons. Hidden by default — useful for browser-based use, not needed for OBS sources.
OBS tip: Set the URL once at the start of each run. Use /wave?cycle=20 or /wave?cycle=30 depending on which wave your first gym appears. The cycle buttons inside the widget are a convenience for browser-based use — for OBS, just change the source URL directly.
GET /party
Party Strip
6-slot party panel showing every Pokémon's sprite, name, level, types, HP bar, moves, status, and shiny ✨ badge. Fainted Pokémon are automatically dimmed. Supports two layouts via the ?layout= param.
OBS Source Widget
Horizontal — /party or /party?layout=horizontal
OBS tip: Recommended size ~840×175px. Great placed along the bottom of your scene.
Vertical — /party?layout=vertical
OBS tip: Recommended size ~340×530px. Works well as a side panel beside your game capture.
GET /stats
Run Stats
Panel showing wave count, current biome, game mode, a live run timer (counts up between server polls), shiny count, and alive Pokémon count.
OBS Source Widget
Preview
OBS tip: Recommended size ~230×240px. Pairs well with the wave widget — stack them vertically in a side panel.
GET /card
Single Slot Card
Full detail card for a single party slot — sprite, name, level, types, ability, passive, tera, status, stat stages, HP bar, and all 4 moves. Uses the same shared rendering code as the party strip. Great as a focused OBS browser source for one Pokémon.
OBS Source Widget
Preview — slot 0
ParameterTypeDescription
slot 0–5 Party slot to display. Default: 0.
OBS tip: Recommended size ~320×175px. Use one browser source per slot you want to feature. Rendering logic is shared with /party — any style update applies to both automatically.
GET /sprite
Sprite by Slot
Serves a sprite by Pokémon name and form. Identity-based URL means the browser caches each sprite indefinitely — no flickering. Without ?raw returns a transparent HTML page (OBS browser source). With ?raw returns raw image bytes (for <img src>).
API / Redirect
Live sprites — slots 0–5 (updates every 2s)
ParameterTypeDescription
name string Pokémon name (e.g. Charizard, Zacian). Required.
form string Form name (e.g. crowned, mega). Empty string for base form.
raw flag Return raw image bytes instead of an HTML page. Use when embedding in an <img src> tag.
OBS browser source: http://localhost:3000/sprite?name=Charizard&form=
Inside an <img> tag: <img src="http://localhost:3000/sprite?name=Charizard&form=&raw">
GET /names
Slot Names
Returns the name (or nickname if set) of Pokémon in the party. Without a param returns all 6 slots as an array. Pass ?slot=N to get a single slot. Empty slots return null.

Customization
Every visual property is controlled by a CSS variable. Paste overrides into the Custom CSS field of any OBS browser source. Variables cascade — override once and it affects everything.
How to customize
In OBS, right-click a browser source → Properties → scroll down to Custom CSS. Paste your overrides there. They apply on top of the default theme without touching any files.
